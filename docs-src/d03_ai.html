AI pipeline

The model interprets. The code decides.

Colour marks authority, not technology. Nothing the model says about correctness reaches the student until deterministic code has confirmed it.
AI-generated interpretation — reads, narrates, names, phrases
Deterministic logic — decides truth, mastery and eligibility
Persistent learner data — remembered across sessions
INPUT

The student's work

A photograph of handwriting, or lines typed directly. Typed working skips the vision stage entirely — the student has already told us what each line says.

CONTEXT

What the model is given

The subject's concept shortlist, prior extracted steps, and the student's own recurring gaps and mastery scores.

AI · STAGE 1

Read & narrate

One multimodal call reads the handwriting, restates each line as a claim, and proposes a concept and misconception. Combined from three calls to survive free-tier quotas.

pipeline/analyze-work.ts
AI · CONFIDENCE

Ask when unsure

Low-confidence handwriting pauses the pipeline at needs_confirmation and asks the student to check the reading — rather than diagnosing a line it guessed.

CODE · THE GATE

Verify every transition

For each pair of lines, mathjs tests whether the transformation preserves the solution set. The first failure is the divergence; later failures are its consequences.

verification/verify-step.ts
CODE · NAMING

Prove the misconception

Where the algebraic signature is unambiguous, the catalogue code is derived — not asked for. The same student error always produces the same code.

diagnosis/detect-misconception.ts
AI · GROUNDED

Explain the repair

RAG retrieval pulls curated chunks for that concept; the model must ground its wording in them and cite the chunk ids it used. Without a provider, the chunks are surfaced directly.

rag/retrieve.ts · explain-gap.ts
AI · TARGETED

Build the intervention

Practice problems whose wrong options are real documented misconceptions, and a teach-back rubric.

CODE · EVIDENCE

Score mastery

A 0–100 EMA (α = 0.35). Transfer success is weighted +12 against practice's +6, because transfer is the stronger evidence. No model judges this.

pipeline/update-mastery.ts
DATA · MEMORY

Learner state

MasteryRecord, LearningEvent, Gap status and misconception history — the context that feeds the next diagnosis.

When the model is unavailable, the pipeline does not stop

A free-tier rate limit is a certainty, not an edge case. Every stage after reading has a deterministic substitute.

Classification

The offline classifier reads the same verified algebra and picks the concept from the shape of the error — reporting low confidence, out loud.

Explanation

Retrieved chunks are surfaced directly alongside the verifier's account of what changed.

Reading a photo
