LAYER 05

Verification

The layer that decides what is true. Zero AI.

Algebra verifier

mathjs proportionality check: does the transformation preserve the solution set?

verification/math-verifier.ts

Domain routing

Per-step-pair: algebra, quantitative, or chemical — chosen from the shape of the lines, not the subject.

verification/verify-step.ts

Misconception catalogue

17 codes plus UNCLASSIFIED. Where the signature is unambiguous the code is proved outright — no model involved.

diagnosis/misconceptions.ts

“Uncertain” is a result

Unparseable lines are never reported as errors. Silence beats a false accusation.
