The GapFinder loop

One mistake becomes a map

Traditional tools end at step 3. GapFinder treats a wrong answer as the start of the loop — and closes it only when the repair survives without help.
01INPUT

Work

A photo of handwriting, or typed lines. The whole attempt — not just the answer.

02AI

Reasoning

Each line is restated as a claim, so the working becomes a chain of steps.

03CODE

Verification

Every line is checked against the one above it — by algebra, not opinion.

04CODE

The gap

The first line that stopped following. Everything after it is a consequence.

05CODE · AI

Misconception

Named from a catalogue of 17 codes, so the same habit is countable across weeks.

06AI

Teaching

A grounded explanation, a computed diagram, and the repair worked through.

07AI · CODE

Practice

Problems built for that misconception — every wrong option is a real error.

08CODE

Verified mastery

Transfer and Exam Mode re-test with no hints. Two questions minimum, or the verdict is “uncertain”.

AI — reads, narrates and phrases. Never decides.
CODE — algebra decides what is true, and what mastery is worth.
DATA — every stage persists its own artefact as it is computed.
