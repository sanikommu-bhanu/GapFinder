The eval harness

The core claim, measured case by case

Fifteen fixed worked solutions with known error locations, run through the real verification and divergence engine. It touches no model, no database and no network — so a regression in the deterministic core cannot hide behind a good day from an API.

What each case asserts: (1) the first divergence is found at the right step; (2) every later step is classified correctly as a downstream consequence or an independent error; and (3) where a corrected line is derived, solving it yields the same answer as solving the line it came from — so a “correction” can never quietly change the problem.

THE CASE THAT MATTERS MOST

alternative-valid-approach-01 reaches the right answer by a different route and must not be flagged. A tool that marks an unusual but valid method as wrong is worse than useless — it teaches a student to stop thinking for themselves. This is the case a naive “compare to the model solution” implementation fails.

WHY TWO CASES SKIP RATHER THAN PASS

Both need an image fixture, and none exists. The handwriting stage is verified by live manual use only. The harness reports them as SKIP and excludes them from the accuracy figure rather than quietly counting them — the reasoning 100% is over 13 scored cases, not 15. Refusing to inflate a denominator is the same discipline that makes the other four numbers worth reading.

WHERE IT EXTENDS — AND WHY THE EXTENSION IS CHEAP

Wider algebra

Quadratics and multi-variable rearrangement follow the same verifier contract — a domain module, not a redesign.

More subjects

A verifier, a routing rule, catalogue entries and seeded chunks. Diagnosis, teaching, practice and mastery come for free.

More providers

Deeper corpus

Concepts, chunks and codes are data, not logic — growing the curriculum never touches the engine.

Drawn deliberately

What this build does not claim

A system that reports its own boundaries can be trusted on the things it does assert. Each line below is a place where the honest answer was to record less than we could have displayed.

HINTS ARE NOT YET COUNTED

Independence is derived from the attempt index — a row count, and therefore a fact. A first-attempt success after reading a hint still scores as unaided, because no surface currently records that the hint was read.

Why it is stated rather than papered over. The parameter exists and is honoured everywhere downstream; what is missing is the input, not the mechanism. Inferring it would mean guessing at a number the product then shows a student as if it were measured.

SIGNATURES ARE DEEPEST IN ALGEBRA

Linear algebra has the richest set of provable signatures. Chemistry and physics have fewer; biology has none, and its diagnoses are matched against the catalogue by the model rather than proved from the numbers.

The distinction is stored, not hidden. Every diagnosis carries a basis of proved or matched, and the two are never merged — so a model-chosen label can always be told apart from an algebraic proof.

THE EVAL IS A REGRESSION HARNESS

Forty-five assertions over fixed fixtures whose expectations were written by hand, as pedagogical claims independent of the implementation. It runs in milliseconds with no model, no database and no network.

What that entitles us to say. That the engine still behaves exactly as specified, and that a regression cannot slip through unnoticed. Not that the numbers generalise to arbitrary unseen student work — a claim that size would need a dataset this project does not have.

HANDWRITING IS VERIFIED BY USE, NOT BY FIXTURE

Two eval cases need an image fixture and none exists, so the harness reports them as SKIP and leaves them out of the denominator rather than quietly counting them as passes.

The reading stage is exercised live across all four subjects before every release, and the pipeline pauses to ask the student when a line is genuinely ambiguous — which is the correct behaviour for a system that must never accuse someone of a mistake they did not make.

None of these weakens the central claim. Locating the first divergence, separating carried error from fresh error, proving the misconception where the algebra allows it, and choosing what happens next are all decided by deterministic code and measured every run. The limits above sit at the edges of that core — and naming them is what makes the numbers in the middle worth reading.
